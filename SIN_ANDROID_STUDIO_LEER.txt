CHICHASONIC - CREAR APK SIN INSTALAR ANDROID STUDIO

Este paquete contiene exactamente el codigo Android V4 con un flujo de GitHub Actions
adicional para que GitHub compile el APK en la nube.

REQUISITOS: cuenta GitHub; navegadores en PC para subir archivos al repositorio.
NO necesitas instalar Android Studio ni Android SDK en tu PC.

PASOS:
1. Entra a https://github.com/new y crea un repositorio PRIVADO con nombre chichasonic-gps-android.
   Deja sin README inicial, sin .gitignore y sin licencia.
2. Descomprime este ZIP en tu PC.
3. Dentro de la carpeta chichasonic-app, selecciona su CONTENIDO completo,
   incluida la carpeta .github (es importante).
4. En tu repositorio nuevo, usa 'uploading an existing file' o Add file > Upload files
   para subir todos los archivos y carpetas; confirma Commit changes.
   Si la web no admite arrastrar carpetas, usa GitHub Desktop o git para enviarlas.
5. Ve a Actions > Crear APK Chichasonic GPS > Run workflow si no arrancó solo.
6. Abre la ejecución terminada con marca verde y descarga el artefacto
   'CHICHASONIC-GPS-ANDROID-V4-APK'. Recibirás un ZIP que contiene app-debug.apk.
7. Copia el archivo app-debug.apk al Android e instálalo (habilita instalar apps
   desde esa fuente cuando Android lo solicite).
8. Permite Ubicación precisa y Notificaciones. En batería elige Sin restricciones.
   Inicia seguimiento con pantalla ENCENDIDA antes de bloquearla.
9. Comprueba en otro teléfono que el mapa se actualice con el Android bloqueado.

IMPORTANTE:
- Es un APK de prueba, NO una versión final revisada ni publicada en Play Store.
- La compilación puede fallar: envía el registro de la acción si ocurre.
- El seguimiento persistente depende de permisos, conectividad y restricciones Android.
- No abras dos transmisores de GPS simultáneos (web y aplicación Android).
- No compartas ni publiques ubicaciones reales; haz pruebas con autorización.
- No agregues ninguna clave privada de Supabase al repositorio.
- Tu Worker de Cloudflare y la web actual no se modifican.
